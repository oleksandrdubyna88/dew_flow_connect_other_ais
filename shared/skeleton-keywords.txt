# The language keywords a skeleton may contain — a CACHE of a derivation, not a list
# somebody wrote. They are the anonymous symbols of each tree-sitter grammar, which the
# grammar knows exactly; `TreeSitterNormalizer.KeywordsOf` reads them off it for that reason.
#
# ONE list, read by two things that must not disagree:
#   - the ingest server's alphabet check, which must not ship 60 MB of native grammars to ask
#     a parser for a word list;
#   - `TheKeywordsAreOneListTests`, which asserts this file still equals what the grammars say.
#
# So a grammar bump that changes a keyword is a RED TEST rather than an ingest server quietly
# refusing skeletons that are perfectly good. Regenerate it in the same change as the bump.
